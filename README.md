# OxyPulse

OxyPulse is an experimental Python project for market-data analysis, strategy evaluation, risk controls, and guarded OKX derivatives execution with Telegram operations.

## Safety

This repository is source code for inspection and development. It is not financial advice, a production deployment, or a promise of trading performance. No live credentials or runtime account data are included. Review the code and safeguards independently before connecting any exchange account. Do not use production credentials or live funds without separate security, operational, and financial review.

## Setup

Use a supported Python version and install the pinned dependencies from `requirements.txt`. Copy `.env.example` to a local `.env` and set credentials only in that local file. Never commit `.env`, account data, databases, or logs.

This source snapshot does not start the bot. Starting any live trading process requires a separate operator decision and environment-specific checks.
